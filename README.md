# Netherite — landing page

Landing page for [Netherite](https://github.com/Im-Fran/Netherite), built with Angular (Vite dev server via `@angular/build`) and Tailwind CSS v4. Colors come from the app's default **Netherite** theme ([`Theme.swift`](https://github.com/Im-Fran/Netherite/blob/dev/Packages/NetheriteCore/Sources/NetheriteCore/Vault/Theme.swift)), light and dark.

```bash
npm install
npm start        # dev server on http://localhost:4200
npm run build    # output: dist/netherite-landing/browser
```

## Cloudflare Pages

- Production branch: `main`
- Build command: `npm run build`
- Build output directory: `dist/netherite-landing/browser`
